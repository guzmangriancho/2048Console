# 2048

Simple java console replica of the classic 2048 game with a local leaderboard system, created for Qaracter Academy by Guzmán González de Riancho.

---

## Controls

* **W**: Move Up
* **S**: Move Down
* **A**: Move Left
* **D**: Move Right

## Rules

1. Join tiles with the same number to merge them into one.
2. Every time you move, a new number appears in an empty spot.
3. The game ends when the board is full and no more moves can be made.
4. Get **2048** to win!

## Menu

1. **Start Game**: Create a new board and begin playing.
2. **High Scores**: View the Top 10 scores saved in the local system.
3. **Exit**: Close the game.
